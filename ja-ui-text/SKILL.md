# 日本語の UI 文言

ユーザーの目に触れる文言だけが対象。コメント、コミット、文書はそれぞれの決まりに従い、この skill の書き方を持ち込まない。

## 文体

- エラー、警告、知らせ、説明文は「です・ます」で書く。「〜ない」「〜できない」で終えない。
  - 「プロジェクトがない」→「プロジェクトが見つかりません」
  - 「〜はもうある」→「〜はすでに存在します」
  - 「〜を読み込めない」→「〜の読み込みに失敗しました」
- ボタン、メニュー項目、見出し、ラベルは「する」を付けずに体言止めか連用形で終える。
  - 「承認する」→「承認」、「テーマを切り替える」→「テーマを切り替え」、「新しいノート」→「新しいノートを作成」
- 進行中の表示は「〜しています」。「フォルダを選択しています」「削除しています」

## 語の選び方

和語の言い回しより、ほかのアプリで見慣れた UI 用語を使う。

| 避ける | 使う |
| --- | --- |
| 選ぶ | 選択 |
| 消す・外す | 削除 |
| 足す・入れる | 追加 |
| 入れる（アプリやプラグインを） | インストール |
| 作る | 作成 |
| 探す | 検索 |
| 送る | 送信 |
| つなぐ・つながり | リンク |
| 受け持つ | 対応・処理 |
| 落とす・離す | ドロップ |
| やめる | キャンセル |
| 取り消す | 元に戻す |
| あとで | 保留 |
| たたむ・開く（階層を） | 折りたたむ・展開 |
| 字体・文字の大きさ | フォント・文字サイズ |
| やること | タスク |
| 下の階層 | サブ〜（サブフォルダなど） |
| 並べ方 | 並び順 |
| 〜したもの | 〜した項目 |

- 並び順の名前は「〜順」でそろえる（更新順、名前順、件数順）。
- 遠回しな説明的ラベルより、短い名詞にする。「前に付ける文字」→「接頭辞」、「拡張子ごとの数」→「ファイル形式」
- 同じものは画面をまたいで同じ語で呼ぶ。言い換えるときは、そのアプリの中を全部そろえる。

## エラーと警告

- 何が起きているかだけを書く。「〜すると使えるようになります」のような対処の文は付けない。
  - 「magick が見つかりません。magick をインストールすると使えるようになります」→「必須の外部ツール「magick」が見つかりません」
- 影響を書くときは「〜ため、〜できません」「〜ため、一部の機能を利用できません」の形にする。
- 対象は種類の名前を前に付け、「」で囲む。`プラグイン「{id}」`、`外部ツール「{name}」`、`設定項目「{key}」`
- 内部の呼び名でぼかさず、実際のファイル名や用語を出す。「処理部分」→「plugin.wasm」
- 拡張子は「.」を付ける（`.psd`）。略語は大文字にする（ID、ZIP、URL）。
- 比べる値は括弧で添える。「インストール済みのバージョン（0.1.0）がライブラリの記録（0.2.0）と異なります」

## 状態、空の表示、件数

- 状態の札は漢字 2〜3 字にそろえる。有効、無効、未導入、未検出、未確認、使用中、保留中、承認済み
- 空の表示は括弧で囲まず、何がないかを書く。「（説明はまだありません）」→「説明はまだありません」、「まだ何もありません」→「まだ項目がありません」、「見つかりません」→「一致する項目がありません」
- 項目やファイルの数は「件」で数える。「12 個を取り込む」→「12 件のファイルを取り込む」

## 表記

- 日本語と英数字の間には半角スペースを入れる。「ZIP ファイル」「AI に質問」「12 件」
- コロンは、前が日本語なら全角「：」、英数字なら半角「: 」。「対応形式：画像・動画」「類似度：高」「読み込みに失敗しました：{e}」「{path}: ZIP ファイルを選択してください」
- 範囲は「〜」。「10〜32 px」
- 並列は「・」、操作の言い換えは「 / 」。「閉じる / 前の画面に戻る」「表示 / 非表示」

## 見直すとき

1. 対象の文言を、画面に出る文字列（JSX のテキスト、`label`・`title`・`aria-label`・`placeholder`、エラーの文字列、ストーリーや見本データの文言）から集める。
2. 上の決まりに照らして直す。見本データやストーリーの文言も本体とそろえる。
3. 同じ語を別の画面やバックエンドのエラーでも使っていないか検索し、まとめて直す。
4. 語の言い換えに迷うもの、決まりに当てはまらないものは、勝手に決めずに候補を示して選んでもらう。
