# 文書記載

確認できた事実に基づいて文章を作成または編集する。

## 進め方

1. 依頼、資料、会話から確認できる事実を特定する。
2. 推測、仮定、見積もり、解釈を事実から分ける。
3. 確認できた事実だけを無条件に記載する。
4. 未確認の内容が必要な場合は、その性質が分かる表現を該当箇所に添える。
5. 完成後に各主張の根拠を見直し、根拠のない断定を除く。

## 正確さ

- 確認できた事実に基づいて書く。
- 推測や仮定など未確認の内容は事実と区別し、該当箇所にその旨を明記する。
- 根拠のない情報を事実のように断定しない。
- 資料にない情報を補って文章を滑らかにしない。
- 不明な内容は「不明」「未確認」などと明示するか、文章に不要なら省く。

## 表現

未確認の内容には、種類に応じて「推測」「仮定」「見込み」「解釈」「例」などの表示を使う。文書全体への一括した注意書きだけで済ませず、該当箇所との対応を明確にする。

確度を表す言葉だけで事実性を装わない。「可能性が高い」と書く場合も、その判断を支える根拠があるか確認する。

## 最終確認

- 固有名詞、数値、日付、因果関係に根拠があるか。
- 推測を事実として読める箇所がないか。
- 情報がない部分を無意識に補っていないか。
- 原文を編集した場合に意味や確度を変えていないか。
